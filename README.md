# 📊 Sentiment Analysis on Amazon Reviews

This project analyzes Amazon product reviews to understand customer sentiment and extract useful insights.

---

## 🔍 Project Overview

- Dataset: Amazon Reviews (first 5000 rows)
- Goal: Identify whether reviews are Positive, Negative, or Neutral
- Approach: Data cleaning → Sentiment analysis → Visualization → Insights

---

## 🛠️ Tools & Technologies Used

- Python
- Pandas
- Matplotlib / Seaborn
- TextBlob

---

## ⚙️ Steps Performed

1. Data Cleaning
   - Removed null and duplicate reviews
   - Selected relevant columns (Text, Score)

2. Sentiment Analysis
   - Used TextBlob to calculate polarity
   - Classified reviews as Positive, Negative, Neutral

3. Data Visualization
   - Bar chart (Sentiment count)
   - Pie chart (Sentiment percentage)
   - Rating vs Sentiment analysis
   - Review length analysis (boxplot)

---

## 📊 Key Insights

- Majority of reviews are positive  
- Negative reviews highlight issues related to product quality and taste  
- Negative reviews are generally longer than positive ones  
- Ratings and written reviews do not always match  

---

## 💡 Business Recommendation

- Improve product quality based on negative feedback  
- Monitor customer complaints regularly  
- Focus on customer satisfaction to increase positive reviews
